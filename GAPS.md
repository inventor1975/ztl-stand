Five small tasks, each aimed at a different weak spot: thermal chain, mechanical stack-up, RC cutoff, battery cell
count, divider over temperature (`examples/tasks/`). All five now run and are held as regression tests (18/18).

|---|---|---|

**A lesson from Z6 (2026-10-09).** The first version tried a certificate BEFORE asking whether ZTL's exact range
already contradicted the corners. Under a lying judge (the mutation test) the certificate earned the design and hid
the lie. Now the judge's honesty check comes first, and a quantity ZTL bounds exactly is never certified around.

**A second lesson (2026-10-10).** Adding a parameter named `ranges` to `_certify` shadowed it with the function's
own result dict, and the guard "never certify around an exact ZTL range" silently stopped working. The earlier
judge-honesty check still caught the mutation, so no test went red. Found by reading the code while extending it.
