# Prior art and competitors of ztl-stand — survey of 2026-10-13

A web survey by one AI research agent (Claude, general-purpose, ~25 sources), not checked
source by source by me; claims marked [vendor] / [paper] / [secondary] / [background] as the agent labelled them.
"Not found in this search" is not "does not exist"; patents and in-house aerospace tools were not searched.

**Combination not found:** catalog selection + worst-case PROOF over a nonlinear tolerance box + certificates checked
by a small exact-rational kernel + a proved cost lower bound. Each piece exists elsewhere:
- concept prior art: Lemke / Hedrich / Barke, ICCAD 2002 — guaranteed worst-case bounds + deterministic global
  optimum for analog sizing (continuous, no catalogs, no certificate kernel);
- kernel-checked optimality certificates: SCIP exact + VIPR — linear / integer only, no tolerance boxes;
- the logic class (exists design, for all tolerances): dReal exists-forall — delta-relaxed, no certificate, no cost bound.

**Industry practice:** mechanical stack-up (CETOL 6σ, 3DCS, Siemens VA): worst case by extremes, RSS, Monte Carlo,
deep CAD/GD&T — far ahead of us on geometry. Electronics WCCA (ECSS-Q-HB-30-01A, NASA): EVA / RSS / Monte Carlo;
PSpice Advanced Analysis picks the worst case by sensitivity and its own guide shows wrong results for non-monotonic
outputs [vendor doc] — the hole a proof closes. Commercial catalog selectors: CircuitMind ACE (cost-optimised selection,
guarantee type not public), JITX voltage-divider solver (corners, no certificate) [secondary / vendor code].

**Behind:** no CAD / geometry / GD&T; no SPICE device models, dynamics, AC / transient, aging, radiation; no GUI / PLM;
walls of 16 coupled tolerances and 6 symbolic linear unknowns; certifiers accept EVA / RSS / MC, not proof
certificates; single author, no track record; the kernel is ours, not Lean / Coq (VIPR and Gappa -> Coq have older
trust bases).
