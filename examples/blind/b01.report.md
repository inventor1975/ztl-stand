- G = 79.3 GPa +-2% (`tolerance` 0.02).

- Laws k = G d^4/(8 D^3 n), F = k (L0 - L), the Wahl factor K_w = (4C-1)/(4C-4) + 0.615/C with C = D/d,
  tau = K_w 8 F D/(pi d^3), Ls = (n+2) d. Units checked on every law.
- Requirements: F_inst in 140..240 (two ops), F_full <= 420, tau <= 650 MPa, gap >= 0.5 mm. Objective: minimise price.

## APPROXIMATED
- pi: not a rational. Used a bracketed given 3.14159..3.14160 (as in t3). Safe (sound bracket), slightly wider than truth.
- n, d, D, L0 treated as continuous ranges: the whole interval is checked, which is what "all tolerance combinations" asks. Same meaning.
- "Solid length >= 0.5 mm shorter than full-lift length" cannot be a bound that is an expression, so I added a derived
  `gap == (Lins - lift) - (n+2)*d` and required gap >= 0.5. Exact rewrite, no change in meaning.
- k and K_w put in `define` (givens/catalog only), not as derived quantities, to stay in the supported class. Same maths. F_full and tau
  are separate derived quantities that each expand k themselves (tau does not reference the derived F_full). Same numbers, no loss.
- No approximation changes the answer's safety direction, as far as I can tell.
