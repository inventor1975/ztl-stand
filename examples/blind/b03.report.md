# b03 report: booster pump (problem 3)

## EXPRESSED FAITHFULLY
- dz 12..18 m; D 52..53 mm; L 120 m; SK 7.5..9.5; g 9.81; rho 983..998 kg/m3.
- Four pumps as a listed catalog: H0 +-3%, a +-5%, eta as absolute ranges (+-0.03), prices.
- Operating point H_pump = H_sys, with V = Q/(pi D^2/4) and H_sys = dz + (fL/D+SK)V^2/2g (algebra done by me).
- Requirements: Q in 9..14 m3/h, P_shaft <= 1.5 kW. Objective: cheapest price. Units checked.

## APPROXIMATED
- pi: not exact in the format. Given as range [3.14159265, 3.14159266] (safe).
- f (Swamee-Jain): the format has no log10 and no power Re^0.9, so I bounded f OFFLINE with python:
  f in [0.0201, 0.0257] over D 52..53, nu 0.47..1.31e-6, Q 6..20 m3/h. The stand never sees eps, nu, Re.
  The Q window is my assumption: it is safe only if the true Q stays in 6..20 (it does: Q came out 9.2..12.8 m3/h),
  but this check is outside the stand. Safer (the range is wide, corners lose the f-Q link) but unvouched.
- Q: not a quantity, because Q is implicit (f depends on Q) and needs a square root. I solve for Qsq = Q^2
  in closed form: Qsq == (H0-dz)/(a+CS). The window 9..14 m3/h became Qsq within [(1/400)^2, (7/1800)^2] (m3/s)^2.
  This is exact for Q >= 0.
- P_shaft: needs Q, but only Qsq exists. So I bound P^2 == KP*Qsq*H*H, with KP = (rho g/eta)^2. The requirement is P^2 <= 2250000 W^2.
- Units: Q in m3/s (no "h" unit), so the pump coefficient a was converted by me: a*3600^2 (0.075 -> 972000, etc.).
- Temperature coupling: nu and rho both come from T; they are given as independent ranges. Safer (superset).
- f, D, SK, L are treated as independent, although f depends on D. Safer.

## COULD NOT EXPRESS
- log10 / powers with a non-integer exponent (Swamee-Jain). No function law other than + - * /.
- An implicit equation for the operating point where a derived quantity enters through a nonlinear function (f(Q)).
  I had to freeze f at an outside bound. No fixed-point or root-finding law.
- sqrt (Q from Q^2), so no direct Q requirement or output; a constant pi (no built-in); a unit for hours (m3/h).
- A correlated pair of givens (nu(T), rho(T) from one T): the format only has independent boxes.
- Law-bounded value of a quantity from a table (nu(T)): a function of a given.

## TOOL OUTPUT
- First tries crashed (Python traceback, not a BRICK ERROR): ValueError "unknown quantity or malformed arithmetic: 'Qsq'" (also 'Q2', and 'H').
  Cause found by bisection: a nonlinear definition (Psq == KP*Qsq*H*H) combined with the implicit linear form
  Qsq*(PUMP.a + CS) == PUMP.H0 - dz. With the explicit form Qsq == (...)/(...) it runs.
- Final: verdict EARNED, design PUMP = P2 (H0 32, a 1.1664e6 SI, eta 0.55..0.61), price 510, "optimal: true, every cheaper design was refuted".
  Only 2 of 4 designs were tried (P1 failed; P3/P4 not tried after the first EARNED, they cost more).
- guaranteed: Qsq [6.5125e-06, 1.26024e-05] (ZTL outer range); Psq [378313, 2250000] "certificate checked exactly (128 pieces)".
  Qsq range gives Q about 9.2..12.8 m3/h. The Qsq/H/Psq bounds are labelled "interval reading, sound, may be wider than the truth".
- judge: ZTL 601b59c. Runtime a few seconds.

## DOES THE ANSWER LOOK RIGHT
Upper end of Qsq for P2 by hand (python): dz=12, H0=32*1.03=32.96, a=1166400*0.95=1108080, D=0.053, SK=7.5, f=0.0201:
A = pi*0.053^2/4 = 2.2062e-3; CS = (0.0201*120/0.053+7.5)/(2*9.81*A^2) = 555099.6;
Qsq = (32.96-12)/(1108080+555099.6) = 1.26024e-05. Tool: 1.26024e-05. It matches.

## DOC GAPS
- BRICKS.md does not say a nonlinear definition fails (with a traceback, not a BRICK ERROR) when it uses a derived quantity
  that is defined by an implicit linear law with a toleranced coefficient (`X*(a+CS) == ...`). Use the explicit form `X == .../...`.
- "A derived quantity equal to a product" is allowed, but a product of 3 derived/given factors (Qsq*H*H) works only because H and Qsq have explicit laws; not stated.
- No statement that `^` is missing in laws (I avoided it); no list of allowed law functions.
- The unit list lacks h (hour) and bar/L; the guide says "units: V A ohm W ..." but "kg" works via prefix k + g; not documented.
- `eta` ranges: only relative `tolerance` or absolute `range` exist; the guide says so, but the case "+-0.03 absolute" is only handled by writing the range by hand.
