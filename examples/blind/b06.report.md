# b06 report - problem 6 (amplifier + RC anti-alias filter, two modes)

## EXPRESSED FAITHFULLY
- Rf 39k +-1%, Rg 4.3k +-1%, R 15k +-1%, each with its own tempco in [-100,+100] ppm/C (separate given `af`,`ag`,`ar`, independent), referenced to 25 C via `define` (e.g. `RfT = Rf*(1+af*(T-25))`).
- Two modes, cold (T=-20) and hot (T=70): `T` is a given (base 25) that each mode overrides. Same requirements in both modes (top-level).
- Gain G = 1 + Rf/Rg (as `G*RgT == RgT + RfT`); cutoff fc = 1/(2*pi*R*C) (via tau = RrT*CT); requirements fc within 990..1140 and G within 9.8..10.3.
- Capacitor catalog: 4 listed items, 10 nF, tolerance (10/5/2/1 %), drift as a range field `d`, price, kind label. Objective: minimize price.

## APPROXIMATED
- **A(10 kHz) >= 19 dB.** The format has no log10/sqrt. I did the algebra by hand: A>=19 dB <=> (f/fc)^2 >= 10^1.9-1 = 78.4328 <=> f/fc >= 8.85623. I put in a derived `r = fin*2*pi*tau` (= f/fc) and the requirement `r >= 8.8563` (rounded UP, so it gives 19.00007 dB). The constant is mine, not the tool's; the rounding is conservative (safer). The requirement is no longer "A in dB" but "f/fc".
- **Capacitor drift per mode.** The problem says "drift listed for the given extreme" but the catalog gives only a range across -20..70 C, without saying which end is cold and which is hot. Modes cannot change catalog fields, so the full drift range is applied in BOTH modes, independent of the tolerance. This is pessimistic (safer): it covers both modes' real drift.
- Tolerance and drift of C are treated as independent (worst case = sum); the problem does not say otherwise.
- Tempco of each resistor treated as an independent random-in-range value (not a fixed batch value); this is the problem's own reading ("+-100 ppm").
- pi bracketed [3.14159, 3.14160] as in t3 (small widening; unknown effect, tiny).

## COULD NOT EXPRESS
- Transcendental laws: log10, sqrt (attenuation in dB), atan/tan, exp. Only +,-,*,/ exist. I removed the log by hand-solving the inequality; the tool never sees the dB law.
- A catalog field whose value depends on the mode (drift at the cold extreme vs at the hot extreme).
- Requirement stated in dB on a quantity defined by a log law (needs a transformed requirement, see above).

## DOES THE ANSWER LOOK RIGHT
Checked by hand: cold, T-25 = -45. Rf = 39000*1.01 = 39390; RfT = 39390*(1+1e-4*45) = 39390*1.0045 = 39567.26. Rg = 4300*0.99 = 4257; RgT = 4257*(1-1e-4*45) = 4257*0.9955 = 4237.84. G = 1 + 39567.26/4237.84 = 1 + 9.3366 = 10.3366 > 10.3. Matches the tool. Also fc nominal = 1/(2*pi*15000*10e-9) = 1061.03 Hz; the guaranteed C3 range 1022..1102 matches my estimate (+-3.75%, i.e. 1% + 0.45% resistor, 2% + 0.3% capacitor).
Note a physical reading: the amplifier gain spec 9.8..10.3 is itself unreachable for these resistors over -20..70 C, so the true answer to the question "which capacitors" is "none, because of G, whatever the capacitor".
