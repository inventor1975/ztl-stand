# Blind report, problem 12 (dosing regimen across weights)
Brick: examples/blind/b12.json. Final verdict: REFUTED (matches an independent corner check, see below). 5 attempts to run (first 4 were errors, see DOC GAPS).

## EXPRESSED FAITHFULLY
- Weight 55..95 kg as a `range`; V = 0.70 L/kg * W * Vf with Vf = 1 +-15%; CL = 0.060 L/(h kg) * W * CLf with CLf = 1 +-25% (two independent relative factors).
- k = CL/V as a define (W appears in both, so it cancels in k, but stays in Dose/V).
- Catalog of 5 regimens (dose +-5% as a catalog tolerance, tau, cost); requirements Cmin >= 10 and Cmax <= 40 mg/L; objective = daily cost.
- Dimension check passed ("checked: every law's dimensions agree").

## APPROXIMATED
- **exp() does not exist** (BRICK ERROR: unsupported expression Call exp). Replaced by exact rational bounds, x = k*tau:
  Cmax = (D/V)(1 + 1/(e^x - 1)) <= (D/V) S5/(S5-1), S5 = Taylor sum to x^5/120 (S5 <= e^x);
  Cmin = (D/V)/(e^x - 1) >= (D/V)/(EXUP-1), EXUP = S5 + x^6/720/(1-x/7) >= e^x (valid for x<7; here x<=1.6).
  So `Cmax` in the brick is an UPPER bound and `Cmin` a LOWER bound of the true values: the brick is SAFER (it can wrongly refuse a marginal design, never wrongly earn one). The derived names are therefore not the true quantities. Error measured at D5 corner: 80.705 vs true 80.69 (0.02%).
- Units L and h are unknown: converted by hand to SI (vd = 0.0007 m^3/kg, cl = 1/60000000 m^3/(s kg), tau in seconds, concentration g*m^-3 = mg/L). Same physics, harder to read.
- Daily cost = cost*86400/tau (tau is in seconds). Not shown in the output, since nothing was earned.
- Dose tolerance +-5% is one catalog tolerance on a single Dose. The real regimen has a sequence of doses, each +-5% independently; the given formula uses one Dose, so same here.

## COULD NOT EXPRESS
- Transcendental functions (exp, ln, sqrt, sin...). Needed by almost any pharmacokinetic, decay, thermal-transient law. Workaround above needs the user to prove bounds by hand.
- Units L (litre) and h (hour), also min, day; unit strings cannot contain parentheses.
- Exact tie of a bound-pair: no way to say "this derived quantity is an upper bound of the true one" so the labelling lives only in names/sources.
- A population percentile statement ("95% of patients") - not asked, so not needed.
