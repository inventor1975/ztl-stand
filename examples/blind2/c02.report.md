# c02 report: Flange bolted joint, torque and separation (problem 2)

Final brick: `examples/blind2/c02.json` (735 designs = 5 bolts x 3 friction states x 49 torque settings, N = 5..53, T = 5 N N·m).
Verdict: EARNED. Cheapest: M12 8.8, as-delivered oil film, 75 N·m (N = 15), $5.60 per 8 bolts, "optimal: true".
A second brick (the literal reading of the preload band, see APPROXIMATED 1) is REFUTED. It sits in my private scratch dir, not in examples/.

## EXPRESSED FAITHFULLY
- Torque-tension law `T = K*d*Fi` as a linear law `Fi*FR.K*BOLT.d == Tstep*TQ.N*W`. K is a catalog field with a range (nut-factor table), W is a given factor 1 +-8 % (wrench), the torque setting is an integer catalog N times Tstep = 5 N·m. So Fi_min..Fi_max comes from the stand's range of Fi, not from my hand algebra.
- Load factor C = 1/(1+km/kb) as a `define` from a catalog field `r`; bolt force under load `sig_ovl*At == Fi + C*Pmax` (Pmax = 20 kN given); clamp force `Fclamp == Fi - (1-C)*Pmax`; fatigue `2*amp*At == C*dP` (dP = 14 kN).
- Requirements: `sig_ovl <= 0.9*BOLT.Sp` (bound as an expression of a catalog field), `Fclamp > 0` (strict, as the text says "positive"), `amp <= 55 MPa`.
- Cost: `8*(BOLT.price + FR.lube)` (lube $0.02 per bolt sits in the friction item).
- Units checked ("checked: every law's dimensions agree"), including `N*m`, `kN`, `MPa`, `mm^2`. mu ranges and the bolt name are labels.

## APPROXIMATED
1. **"Preload 60..75 % of proof load at the target torque considering the scatter" - ambiguous, I picked one reading.**
   - Final brick: NOMINAL preload `Fn = T/(Kn*d)` (nominal K from the table midpoint, perfect wrench) within [0.6, 0.75]*Sp*At. This needs an extra catalog field `Kn` and an extra law. Not conservative relative to the literal reading; it is my interpretation. Nobody checks it but me.
   - Literal reading (the WHOLE scatter range Fi_min..Fi_max inside 60..75 %): impossible, REFUTED for every design. The scatter alone is a factor 1.08/0.92 x 0.17/0.13 = 1.535 for the best friction state (lubricated) against 0.75/0.60 = 1.25 available. The stand's `minimal_conflicts` agrees: {preload>=60 % with stress<=0.9Sp} and {preload>=60 % with preload<=75 %}.
   - The problem's own question presupposes an answer, so I took the first reading. A user who means the literal one gets no design.
2. **Stiffness ratio of M12 10.9**: the text gives km = 3.2 kb "for the 8.8 bolts" and 3.0 kb for "the stiffer long M14". I used 3.2 for M12 10.9 (same joint as M12 8.8) and 3.0 for BOTH M14 grades. Neither is stated. Not conservative-checked; only I check it. (Putting a range [3.0, 3.2] would share one toleranced coefficient over three laws, which BRICKS.md warns may go OPEN; not tried.)
3. **K ranges by hand**: 0.15+-0.02 -> [0.13, 0.17], 0.20+-0.03 -> [0.17, 0.23], 0.26+-0.04 -> [0.22, 0.30]. Exact, no rounding. The mu ranges are labels only: the problem says K is "read from the table", so mu -> K is not modelled.
4. **Wrench error as a factor on the SET torque** (T_actual = T_set*(1 +- 0.08)), not on the full-scale reading. Assumption.
5. **Torque range N = 5..53 chosen by me.** I computed by hand which N put the nominal preload in 60..75 % for each bolt/friction (band from 6.3 to 52.1 in N), so 5..53 covers every candidate. The stand only searches what I listed; whether the range is wide enough is checked by me (python), not the stand. It is complete because the band requirement bounds N from above and below.
6. **Eight bolts** only appear as a factor 8 in the objective. Per-bolt load is given per bolt, so nothing else couples them. Torque is taken per bolt.
7. **Objective ties**: two designs cost $5.60 (M12 8.8 oil N=15 and M12 8.8 dry N=19). The stand returned one and called it optimal; a tie is not flagged.

## COULD NOT EXPRESS
- "Occasional overload (once)" vs the cyclic load: no way to say how many times; handled only by choosing which requirement uses which load (fine here).
- Whether the same bolt/torque must hold "for all" frictions - not asked; friction state is a per-job choice, correctly a slot.
- A derived-quantity bound for the preload band without an extra "nominal" catalog field (`Kn`): the nominal of a range is only the midpoint of the box, and a requirement can use only the box, so I needed a duplicate field.
- Nothing structural in the physics was unexpressible; the wrench/K scatter and the "for all" came out through given tolerances and a range.

## DOES THE ANSWER LOOK RIGHT
- Own python (exact Fractions, written independently of the stand): for the winner N=15: Fi_min = 75*0.92/(0.23*12) = 25.000 kN, Fi_max = 75*1.08/(0.17*12) = 39.706 kN (= 675/17, the judge log has the same). sig_ovl max = (39.706 + 20/4.2)*1000/84.3 = 527.495 MPa. Fclamp min = 25 - (1 - 1/4.2)*20 = 9.7619 kN. amp = (1/4.2)*14000/(2*84.3) = 19.7707 MPa. All equal the stand's numbers.
- Over all 735 designs my python and the stand agree on the EARNED set: 24 of 24, identical (bolt d, Sp, friction, N). Cheapest cost 5.6 matches. No M10 design is earned in either; I did not hand-trace why for each, only the count.
- Did NOT check: the physics of the model itself (e.g. whether bolt force = Fi + C*P is the textbook form - it is the usual one), and my reading of the ambiguous items in APPROXIMATED 1, 2, 4.
- Note for the arbiter: M12 8.8 with oil film passes with sig_ovl max 527 against a 540 limit, so the margin is ~2.4 %; a different stiffness assumption could flip it.
