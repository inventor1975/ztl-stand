# c05 report: Two columns in a pump station frame, column buckling (problem 5)

Final brick: examples/blind2/c05.json (generated by a throwaway python script; the JSON is the deliverable). One run, no retries needed, 1.1 s wall time.

## EXPRESSED FAITHFULLY
- E = 200 GPa exact; Sy as range 330..380 MPa; K_A range 0.7..1.0; K_B range 0.8..1.2; L_A = 1.3 m, L_B = 3.6 m; loads 380 kN +-5 %, 95 kN +-10 %; n_A = 2, n_B = 5/2.
- Two slots SA, SB, each from one catalog of 7 sections (3 round bars, 3 CHS, 1 RHS) with A [cm^2], I [cm^4], price per metre [USD/m]; 49 pairs enumerated.
- lambda = K*L*sqrt(A/I) (as a define plus a derived `lamA`/`lamB`), x = Sy*lambda^2/(2 pi^2 E) = (lambda/lambda_c)^2, allowable load = sigma_cr*A/n as a derived `PallA/PallB` with sqrt, min, max and the built-in pi.
- Requirements: Pall >= applied load (a toleranced given as the bound), lambda <= 120 (A) and <= 200 (B). All for every value in the boxes.
- Objective: minimize SA.pm*LA + SB.pm*LB (price per metre times length), `report: all`.
- Units checked ("every law's dimensions agree").

## APPROXIMATED
1. **Regime switch Euler/Johnson written by me as one smooth-in-form expression** (hand algebra, not given in the problem): sigma_cr = Sy*(1/(2*max(x,1)) - min(x,1)/2 + 1/2). It equals Sy(1-x/2) for x<1 and Sy/(2x) for x>=1 (algebraically; I also checked numerically, max difference 3e-17 over 1e5 random x). Safe in meaning (exact identity), but checked only by me. The stand checks the brick's own formula, not that it is the right buckling rule. Side effect: Sy and the lambda inside repeat, so interval reading loses correlation (outer range of PallB for RHS was [123.5, 255.2] vs true minimum about 142.2 at my grid). Conservative: it can only make EARNED harder, never wrongly easy. Verdicts here were unaffected.
2. **pi in the round-bar A and I**: catalog fields are ranges with pi bracketed to 1e-14 (3.14159265358979..80). Conservative, trivially small. Written by me via python, not by the stand.
3. **Shared Sy and E in both columns**: the same given quantities appear in both columns' laws, as the problem says (one supplier steel). The requirements are separate per column, so the lost cross-column correlation does not matter; no approximation.
4. **"Nominal 355 MPa"** is not represented; Sy is just the 330..380 range (the problem says to take that range). The "nominal" point the stand uses (midpoint 355) happens to equal it.
5. **Slenderness limits** (120 / 200) are read as requirements on lambda over the whole box (my reading).
6. **Pair acceptability**: each column is judged separately; the cost is additive. Fine because the columns are independent.
