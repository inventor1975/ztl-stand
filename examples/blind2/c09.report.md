# c09 report: 12 kWp rooftop PV, inverter and string layout (problem 9)

## EXPRESSED FAITHFULLY
- Three module items, three inverter items with every datasheet number as listed (Pmax, Voc, Vmp, Isc, gamma, beta_Voc, beta_Vmp, price; Vmax, MPPT lo/hi, Imax, Pac, price), with units (%/K written as 1/C).
- Modules per string N as an integer catalog (5..20), strings NP as a listed catalog.
- Cell temperature Tc = Tamb + (NOCT-20)/800*G as a `define`, NOCT as range 43..47 C (the only toleranced input). Voc(T), Vmp(T), Pmax(T) with G/1000 scaling as laws, all units checked.
- Three seasons as three `modes`: winter morning (Tamb -18, G 100, Tc = Tamb+2 by a mode-level define override), winter clear (-18 C, G 1000, NOCT formula), summer hot (38 C, G 1000).
- Requirements: Voc*n <= 0.97*Vmax (winter morning); Vmp*n <= MPPT max (winter clear); Vmp*n >= MPPT min, Pdc <= 1.1 Pac, Pdc >= 0.8 Pac (summer hot); Pstc in [11500, 13500] W; DC/AC in [1.05, 1.35]; 1.25*Isc <= Imax.
- Objective: cheapest hardware (modules*count + inverter), `report: all`.

## APPROXIMATED
1. Strings per MPPT input. The text says "string current (Isc x 1.25) <= MPPT input rating per string input". The inverters have 2 inputs, so NP=3 or 4 means two strings on one input. I hand-coded ceil(NP/2) as a field `spi` of the NP catalog (NP=1,2 -> 1; NP=3,4 -> 2) and required `Istr = 1.25*spi*Isc <= Imax`. This is STRICTER than the literal text (conservative), and only I check it; the stand just multiplies. Literal reading (spi=1 always) in my own python adds 4 passing designs (NP 3/4, e.g. 8x4 M-380) with the same minimum cost 6380.
2. Range of N is cut to 5..20 and NP to 1..4 (my choice; 576 designs). Not conservative in principle (designs outside the range are not examined) but the Voc limit bounds N at about 20 for 1000 V inverters and 11 for INV-8, so nothing physical is lost. Only I checked this.
3. Winter-morning case: the text says T_cell = T_amb + 2 K; I replaced the define Tc in that mode. Voc then does not depend on G at all (the model given has no G term in Voc), so G=100 in that mode is decorative. Faithful to the text, but physically the worst-case Voc is at high G and cold; I did not add that case because the problem did not ask for it.
4. "Vmp in winter at STC-like irradiance" read as Tamb -18, G 1000 with the NOCT formula (Tc = 13.25 C nominal). My interpretation of "STC-like", not an STC cell temperature of 25 C.
5. Percent bounds (97/100*Vmax, 11/10*Pac) are written as expressions of slot fields; the stand does the algebra.
6. Catalog values are exact (no datasheet tolerances were given), so NOCT is the only moving input. A real design would have module tolerance and measurement margin; the problem did not state them.

## COULD NOT EXPRESS
- ceil(NP/inputs) and "number of inputs" as such: no way to say it except pre-tabulating (item 1). A constraint like "NP <= something derived from the inverter" cannot be written because slots are independent catalogs and bounds on a catalog integer need a derived quantity.
- Per-mode quantities of the same name being different (Voc "winter" vs "summer"): not needed here because I used one law set and mode-specific requirements, but only because Tc is the single mode-dependent thing.
- A catalog row that couples module and inverter (e.g. "this module only with that inverter"): not needed.
- Nothing else in the problem was inexpressible.
