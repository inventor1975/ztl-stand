# c08 report: gear hub pressed onto a shaft, press fit (problem 8)

Verdict: REFUTED for all 12 (hub, fit) combinations, every one on the slip-safety requirement. Reproduced by my own python (see below).

## EXPRESSED FAITHFULLY
- All geometry/material givens (d, D, L, Es, nu_s, alpha_s, Rz_s, Rz_h) as exact givens with units.
- Torque 800 N*m +-10% (`tolerance 0.1`), mu in [0.08, 0.14], operating T in [-20, 80] C as ranges; the stand judges the whole box, so "worst mu, worst T, +10% torque" needs no hand-picked corner.
- Hub catalog (E, nu, alpha, allowable stress, price) as 3 listed items; fit catalog as 4 listed items.
- Contact pressure p = delta_eff/(d*K) with K = ((D^2+d^2)/(D^2-d^2) + nu_h)/E_h + (1-nu_s)/E_s (a `define`), delta_eff = I - 0.4(Rz_s+Rz_h) - d(alpha_h-alpha_s)(T-20) (a `define`), T_cap = mu p pi d^2 L/2, hoop = p (D^2+d^2)/(D^2-d^2), assembly dT = (I_max + 20um)/(d alpha_h) <= 230 K.
- Requirements: T_cap >= 2*Tpeak (bound expression with the toleranced Tpeak, taken at its worst end), hoop <= allowable (slot field as bound), dT_a <= 230. Objective min hub + fit price. Units checked ("every law's dimensions agree"), C and 1/C used throughout.

## APPROXIMATED
1. Hub bore H7 (0..+25 um) and shaft deviation merged by hand into ONE interference range per fit: min = shaft_lo - 25, max = shaft_hi (p6 [1,42], r6 [9,50], s6 [18,59], u6 [45,86]). Same meaning, no loss, but the arithmetic is mine; only I checked it. The interference is treated as a continuous variable in [min,max], independent of T and mu (as intended).
2. I_max (needed for the assembly clearance) is a SECOND catalog field typed in by hand, equal to the upper end of the range I. Nothing ties the two; a typo would not be caught.
3. "Slip check at min interference/worst T" and "hoop check at max interference/coldest T" became ONE box over all of I, T, mu, Tpeak for every requirement. Equivalent here (each requirement is monotone, so it picks its own extreme), safe, the stand does it. Not a different case set per requirement, only the full box.
4. delta_eff, K, W=(D^2+d^2)/(D^2-d^2) are `define`s, not derived quantities (the format forced it, see DOC GAPS). Safe; but the temperature term d*alpha_h*(T-20) is then bounded by the stand/ZTL as a coefficient expression, not as a separate row.
5. Hoop stress "shaft included": no extra shaft check was stated with numbers, so I check the hub bore only (the shaft's compressive stress is not in the problem data). Unsafe in the sense that nothing checks the shaft.
6. alpha given as decimals (0.0000115) because "11.5e-6" is not a plain fraction/decimal string; exact, no loss.

## COULD NOT EXPRESS
- Physical validity: when delta_eff <= 0 the formula gives p <= 0 and a negative T_cap (p6/Al etc. show T_cap_min < 0). In reality there is no contact; the stand just treats the formula as valid and refutes it. Harmless for a REFUTED verdict, but the format has no "contact exists" statement except a `valid` clause, and I did not find a way to attach one to a `define`d delta_eff.
- Per-requirement different load cases in one brick other than via modes; I did not need modes, but "the same material range for I in two requirements with separate worst cases" cannot be told apart from the box reading.
- H7 hub bore and the shaft deviation as two separate tolerance sources (hub-side vs shaft-side), so the stand could report which tolerance dominates; they are merged (APPROXIMATED 1).
- The assembly temperature uses I_max only as a number, not as "the maximum of the range I".

## DOES THE ANSWER LOOK RIGHT
My own python (corner enumeration of I, T; mu=0.08; T_peak 880 -> need T_cap >= 1760 N*m):
- H-St C45 / u6: p_min = 55.87 MPa, T_cap_min = 1404.1 N*m (matches the stand's 1404.1 exactly); max hoop 218.4 MPa (matches 218.423); dT_a = 106/(0.05*11.5e-6) = 184.35 K (matches).
- All 12 combinations: T_cap_min is 1404 at best (steel/u6), 801 (CI/u6), 40 (Al/u6), the rest lower or negative; all < 1760. So the REFUTED-for-all-12 verdict agrees with my calculation. (Cast iron / u6 would also fail the hoop limit: 136.3 > 125 MPa. Steel/u6 passes hoop and assembly. Aluminium loses interference when hot, as expected.)
- Not checked: the stand's per-design "by" numbers (they are at its witness, not at the worst point; e.g. the witness for steel/u6 has Tpeak=720, the FAVOURABLE end, so "by 35.9" understates the real miss of 356 N*m); the ZTL/checker internals; the physical meaning of the problem's data (invented).
- Interpretation caveat: the answer "no combination" depends on reading min interference as shaft_lo - 25 um (H7 upper limit), which the problem statement supports.

## DOC GAPS
- BRICKS.md does not say that `coefficient*derived == (expression of givens)` is refused as "nonlinear law"; one must write `X == expr/coefficient`. The error text does not say so.
- A quantity defined by one law and then repeated as X in another `X == ...` gives the misleading message "a law with a function or a defined quantity must define one derived quantity" (nothing about a function was in the law).
- Not stated whether a `define` may contain a ranged given and a ranged catalog field (it can; I used T and FIT.I inside a define).
- `by` in REFUTED designs is at the witness, not worst, documented only in the output (`designs_by`), not in BRICKS.md section 8 (it is there in the list but easy to miss).
- Decimal exponents ("11.5e-6") not mentioned as allowed or not; I used plain decimals.
