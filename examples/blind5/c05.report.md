## APPROXIMATED
1. **Concentration limits rewritten as linear margins (hand algebra, safe if my algebra is right; the stand does not check it by itself).** Continuous B requires requirements affine in B, but N = M/(B+D) divides by B. I wrote `gSi_s == 150*(B+D) - SiO2_m*(E+B+D)` (and Cl, SO4 likewise) required `>= 0`. This is exact (B+D > 0 always since D = 0.023, so multiplying by it is an equivalence). The stand never sees N or the concentrations in the main brick. WHO checks: me (see DOES THE ANSWER LOOK RIGHT), plus a second brick with the unreduced laws (below).
2. **LSI limit turned into an N cap (hand algebra, safe, only I derived it).** LSI = 2.85*log10(N) + K (K collects Alk, Ca, TDS, T, r terms; 2.85 = 1.95 + 1 - 0.1 from the stated formula). Since 2.85 > 0, LSI <= Lmax iff N <= Ncap = 10^((Lmax-K)/2.85), and then `gLSI == Ncap*(B+D) - (E+B+D) >= 0`. K and Ncap are `define`s of givens (log10, pow). The stand bounds gLSI by "interval reading of the definition (sound, may be wide)" plus the checker's own bound, so the bound is checked, but the equivalence LSI<=Lmax <=> N<=Ncap is only my algebra.
3. **Cost at "worst case" = nominal objective with exact top-of-range constants.** I added `Qtop_s` (1.2, 2.0, 2.8) and an exact catalog field `Alkhi` (90 / 240 / 240) as copies of the range tops. Transcription by hand, not linked to the ranges; the stand cannot notice a mismatch.
4. **B upper box 20 m3/h.** Continuous slots need a `to`. R5 forces B_s <= ~13 m3/h anyway (26000/2000 in winter), so the bound cannot change the answer, but it is my addition.
5. **R5 bound as number `26000`** (a given as bound is refused for continuous, see COULD NOT EXPRESS). Same value, no loss.
6. **Composition is one draw for all three seasons** (a slot's range field is one quantity). Safe for R1-R5 here: each requirement involves only one season's composition, and the for-all over a product box is the same as over its projections; R5 does not depend on composition. Not safe for any requirement coupling seasons through composition (none here).
7. `optimal: false`: the reported mix has ~4e-4 m3/h slack above the exact minimum in each season (the stand's LP/rationalisation margin), cost 0.0089 kEUR (0.016 %) above the proved lower bound. Not an approximation of mine, but the answer is "within 0.0089 kEUR of optimal", not "optimal".
