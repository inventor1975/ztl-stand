- Four steels as listed items (SY exact, KIC value with tolerance 0.1 = 90..110 %), one slot ST (chosen once).
- Q = 1.12 constant; sigma = 0.6*SY via `define`; law `ac == Lu*KIC*KIC/(pi*Q*Q*sig*sig)` (K_IC = Q sigma sqrt(pi a) solved for a).
- Requirement ac >= Areq, Areq = 5/2 in (given). Units ksi, in.
- c01.json answers (a): REFUTED, no steel meets 2.5 in. c01c.json is the same with Areq = 0 as a probe, to read every steel's guaranteed worst-case ac (the REFUTED output of c01 lists only the closest design's range).
