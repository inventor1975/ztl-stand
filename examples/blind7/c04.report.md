# c04 report: Hearing protector for a four-station shift (problem 04)

Bricks: `c04.json` (question b: choose the protector), `c04a.json` (question a: no protector, dose and TWA). Generator: `work_c04/gen.py`; my check: `work_c04/check.py`; raw outputs `work_c04/c04.out`, `c04a.out`.

## EXPRESSED FAITHFULLY
- Four period levels as independent ranges (97-101, 91-94, 84-87, 74-79 dBA, unit dBA); durations 2.5/3.0/2.0/0.5 h exact; T0 = 8 h, L0 = 90 dBA, S = 5 dBA, threshold 80 dBA, offset 7 dB as given quantities with units.
- Lowered level Le_i = L_i - (NRR - 7) as a law, with NRR taken from the catalog item.
- Per-period dose fraction d_i == if(Le_i >= 80, C_i/T0 * 2^((Le_i-90)/5), 0). This is C/T with T = 8/2^((L-90)/5). The "below 80 does not count" rule uses the LOWERED level and is a branch. A level of exactly 80 counts ("below 80" is excluded).
- D == 100*(d1+d2+d3+d4), a percent. TWA == 16.61*log10(D/100) + 90 (in brick a).
- Catalog of P1..P6 with NRR and price. The choice is a discrete slot, made once before the uncertain levels (as the general rule says). Requirement D <= 15 (percent). Objective: minimize price. `"report": "all"` so every protector is judged.
- Question (a): a one-item catalog "nop" (NRR 7, so the reduction is 0, price 0). Same laws, with the requirements D >= 0 and TWA >= 0 only as a way to make the stand print the guaranteed ranges.

## APPROXIMATED
- "No protector" is modelled as NRR = 7, i.e. reduction 0. This is exact, but it is my encoding. Nobody checked it except me.
- Brick a's requirements `>= 0` are not problem requirements. They are a device to read the range out. The stand's EARNED there means only "inside [0, inf)".
- TWA is not in brick b (with a protector D can be 0 and log10(0) is undefined). The question does not ask for TWA with a protector.
- The ranges the stand reports are "ZTL, interval reading of the definition (sound, may be wide)". I checked them against my own corner enumeration (below), and they came out tight here.
